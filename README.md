# Enhancing Time Series Forecasting through Multi-Modal Data Fusion

> **Course Project:** ESE 5380 @ UPenn  
> **Repository:** ese-5380-llxx

## 📖 Project Overview

This project introduces a **Feature-Level Multimodal Fusion Framework** designed to address the limitations of traditional time series forecasting models in capturing exogenous volatility caused by real-world events (e.g., breaking news, policy shifts).

Unlike traditional Late Fusion strategies, our approach utilizes a **Dynamic Cross-Attention mechanism** and **Adaptive Gating** to align text embeddings generated by pre-trained language models (BERT) with time-series features in the latent space.

**Key Contributions:**
* **Dual-Stream Architecture:** Effectively fuses numerical time-series data with textual embeddings from foundation models.
* **Dynamic Alignment:** Introduces a Cross-Attention and Adaptive Gating mechanism that allows the model to dynamically weigh the importance of semantic context against historical numerical patterns at each time step.
* **Empirical Validation:** Validated on the **Time-MMD** benchmark (covering Economics, Public Health, and Climatology), demonstrating superior performance in event-driven scenarios compared to unimodal baselines.
* **Critical Analysis:** Provides an in-depth analysis of the interaction between semantic injection and sparse attention mechanisms, revealing a positive synergy with **Informer** (Global Attention) and potential conflicts with **Reformer** (LSH) in periodic domains.
